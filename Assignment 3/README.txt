README

How to Run:
1) Make sure Python is installed
2) Open terminal or command prompt
3) Go to the project folder
4) Run: python main.py or py main.py

How to Use:
- Open: opens file or folder
- Save: saves file changes
- New File: creates file
- New Folder: creates folder
- Delete: deletes item
- Rename: renames item
- Up: goes to parent folder

Dependencies:
- Python 3
- Uses built-in libraries: os, tkinter

Notes:
- Starts in current folder
- Some folders may block file creation (permissions)
- Only empty folders can be deleted
